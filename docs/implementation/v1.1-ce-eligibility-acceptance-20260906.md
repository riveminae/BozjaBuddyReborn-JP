# Remote CE eligibility acceptance

Date: 2026-09-06. Baseline: `35f2912`.
Requirements: 4.2 / 4.3 / 10.3 / 18. Packet: P4-01, audit GAP-05/06.

## Frozen criteria

- An unrestricted Register-phase CE is considered immediately, independent of map
  position, remaining seconds, or the legacy minimum-seconds preference. The real
  UI's enabled button and existing safe click path determine whether a press is possible.
- Closed phases, explicit blocks, duel/large-scale opt-ins, configured priority,
  and event-id tie breaking are preserved.
- Ordinary Relic CEs still require matching territory, activity, and known region;
  a learned matching region works without a map position. Enabled large-scale
  content retains its explicit priority exception.
- The UI no longer offers a minimum-seconds slider. The serialized field stays
  readable but is unused at runtime. Old CE travel-liveness code must not read it.
- No SignUpRunner event arguments, click-settle controls, or one-registration guard
  change in this packet. Existing validators are augmented only.

recruitment button and both fields pass signup/lottery/commence/resume tests.

Initialize/refill, release publication, conflict resolution, and main merge remain
part of the overall objective.
