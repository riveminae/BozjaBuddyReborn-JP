# 六分類の設定画面と独立許可の受入条件

基準日: 2026-09-06。起点: `1152e45`。対象: 要件8.2、14.1/14.2、詳細設計12.2、P11-01。既存値を操作可能にする範囲で要件4.3/5.2も含む。

## 実装前に固定する条件

1. 設定画面の主要タブは順に「周回」「生存」「ロストアクション」「移動」「レジスタンスウェポン」「詳細設定」。既存の戦闘、参加条件、補給、移動、エリア診断、通常使用、コンテンツアクション、パーティ支援は操作可能な場所に残す。
2. ロストアクションの通常表示は本番の生存方針から得る候補。全候補は詳細設定で名前検索できる。表示名は日本語データを使い、取得できない場合は日本語の未取得表示にする。英語クライアントの名前をそのまま使わない。
3. 各行の持込・自動使用は既存の別々の辞書だけを書き換え、保存する。片方の操作で他方や通常使用の対象リストを変更しない。四通りを操作できる。希少品の既定値は本番方針の両方不許可を保持する。画面を開くだけでは設定を書かない。
4. 通常使用が無効でも、生存の許可設定とパーティ支援へ到達できる。通常使用の明示的な発動許可、優先候補選択、支援の明示開始という別の同意を合併しない。
5. レジスタンスウェポンの既存表示を設定画面に再利用し、単独画面も維持する。最初の素材を自動指定しない。既存の停止条件・次の不足素材への継続を設定できる。
6. 移動の既存設定を維持し、既存のデジョン経路許可と費用設定を操作可能にする。費用の調整は詳細設定に置く。飛行や移動中反撃の設定は復活させない。
7. `dotnet run --project tests/SettingsUi/SettingsUi.Tests.csproj` は本番の画面と許可方針をリンクし、ゲーム境界だけを合成する。実際のImGuiコンテキストへ画面を描画し、ゲーム入力ではなくそのコンテキスト内の入力イベントでタブ・許可・検索を操作して終了コード0。例外は捕捉して終了コード1、全体は外側の期限内に終了する。描画と操作を行わない単体検査だけでは受理しない。
8. 同じ固定検査でタブ欠落、二つの許可の混同、既定の希少品許可、検索無視の独立不具合を拒否し、復元後に成功する。既存508件、静的契約、日本語監査、packet再適用2回、Debug/Release、差分検査は終了コード0。既存試験・packet・静的条件を弱めない。
9. 画面操作によるゲーム内使用・転送を実施しない。実機描画、実フォント倍率、クリップボード貼付、第三者レビューと未実装の転送・秘薬上書き・メイン表示の残差異は別に記録する。今回の設定画面でv1.1全体の完了とはしない。

## 証跡

以下はローカル検証。基準実装は上記起点との差分であり、配布済み版や実機の合格を意味しない。

### 条件と検証の対応

- 条件1/4/5/6: 本番の設定画面・レジスタンスウェポン画面を描画し、主要タブの順序、従来の操作への到達、停止条件三種類、継続の許可、明示した素材の選択、移動設定を検査した。設定画面と単独画面は同じ描画処理を使う。
- 条件2/3: 本番カタログ・生存方針をリンク。三つのロールと不明時、日本語データ欠落と復帰、全候補の名前検索、独立許可四通り、保存後の復元を検査した。通常使用の候補リストを変えず、画面を開くだけでは保存・初期素材選択をしないことも確認した。
- 条件7: 既存の描画ライブラリの実コンテキストを使用。観測ラッパーは描画呼出しを転送し、返り値や設定値を置換しない。実際の部品座標へ、その隔離コンテキスト内だけでマウスと文字の入力を与える。外部プロセス側の制限は各実行30秒。未捕捉例外のダイアログを避けるため試験入口で例外を終了コード1へ変換する。
- 条件8: 下記の回帰検査・不具合入力・再適用を実行した。従来の検査、期待値、入力、packet、静的契約は変更していない。
- 条件9: ゲームのサービス境界は合成値。ゲームプロセス・操作・転送は使用していない。実機フォント、倍率、文字の見切れ、クリップボードへの実貼付、第三者による操作、秘薬上書き、転送、メイン画面の残差異は未確認または未実装のまま区別する。

### 独立レビューと残る制約

実装時の結論を渡さない読み取り専用レビューで、要件・固定条件・変更ファイルと試験を確認した。重大・高・中の未解決指摘なし。レビュー担当もインストール済み実行ファイルを指定し、上記画面検査をテスト版51件・安定版46件、それぞれ終了コード0で独立実行した。

文書レビューでは、既定の検索パスにない実行ファイルを再現する手順の不足が中重要度で指摘された。上記の導入先確認と端末内の検索パス設定を追記した。同じ手順でSDK 10.0.400/Python 3.13.7を確認し、画面検査51件/46件を再実行して終了コード0となった。

これは本番描画コードの隔離操作検査であり、実ゲームの受入ではない。既定フォントで描画頂点を確認しており、日本語の実フォント表示品質は未検証。ゲーム内の秘薬上書きと安全な転送は未実装。既存の素材名・ロール名・メイン表示にも残差異がある。P11-01は実機確認待ち、P11-02とP11-06は未完了を維持する。
